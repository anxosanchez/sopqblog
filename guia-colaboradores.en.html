1 Publication Workflow & Editorial Peer Review

To maintain quality and thermodynamic consistency, no post is published without prior editor approval. Contributors can submit simulation cases using two main paths:

1.1 Option A: Pull Request Submission on GitHub (Recommended)

  1. Fork the official repository: github.com/anxosanchez/sopqblog.
  2. Create a feature branch (e.g., post/cstr-bioethanol or post/hysys-debutanizer).
  3. Author your article based on posts/_template_post.qmd.
  4. Place simulation cases in assets/simulations/ and graphics in assets/images/.
  5. Open a Pull Request targeting main.
  6. Our CI pipeline alerts the editor instantly via Telegram and runs taxonomy verification.

1.2 Option B: Hidden Draft Submission (draft: true)

If you have direct write permissions, save your .qmd in posts/ with:

---
title: "Process Simulation of..."
draft: true   # <-- KEEPS THE POST HIDDEN
---

Quarto renders drafts privately without displaying them on the public home page, search indices, RSS feeds, or sitemaps until the editor validates balances and removes draft: true.

## Publication Workflow & Editorial Peer Review

To maintain quality and thermodynamic consistency, **no post is published without prior editor approval**. Contributors can submit simulation cases using two main paths:

```{mermaid}
flowchart TD
    A["Author prepares draft (.qmd) + Files (.hsc/.dwxml/.svg)"] --> B{"Submission Method"}
    B -->|"Option A (Recommended)"| C["Open Pull Request on GitHub"]
    B -->|"Option B (Internal)"| D["Save in posts/ with draft: true"]
    C --> E["Pipeline executes automated checks"]
    D --> E
    E --> F["Automated notification to Editor (Telegram / GitHub)"]
    F --> G{"Editor Review"}
    G -->|"Request revisions"| H["Feedback to author"]
    H --> A
    G -->|"Approved"| I["Merge / draft: false"]
    I --> J["🚀 Automatic Deployment to GitHub Pages"]
```

### Option A: Pull Request Submission on GitHub (Recommended)
1. **Fork** the official repository: [`github.com/anxosanchez/sopqblog`](https://github.com/anxosanchez/sopqblog).
2. Create a feature branch (e.g., `post/cstr-bioethanol` or `post/hysys-debutanizer`).
3. Author your article based on [`posts/_template_post.qmd`](https://github.com/anxosanchez/sopqblog/blob/main/posts/_template_post.qmd).
4. Place simulation cases in `assets/simulations/` and graphics in `assets/images/`.
5. Open a **Pull Request** targeting `main`.
6. Our CI pipeline alerts the editor instantly via **Telegram** and runs taxonomy verification.

### Option B: Hidden Draft Submission (`draft: true`)
If you have direct write permissions, save your `.qmd` in `posts/` with:

```yaml
---
title: "Process Simulation of..."
draft: true   # <-- KEEPS THE POST HIDDEN
---
```

> Quarto renders drafts privately without displaying them on the public home page, search indices, RSS feeds, or sitemaps until the editor validates balances and removes `draft: true`.
