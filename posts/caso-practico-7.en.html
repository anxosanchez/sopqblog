1 Introduction and Process Description

The industrial synthesis of Methyl tert-butyl ether (MTBE) from isobutene (iC_4^=) and methanol (MeOH) represents a canonical chemical engineering problem coupling catalytic reaction kinetics, multicomponent fractionation, and tightly closed recycle streams:

\text{Isobutene } (iC_4^=) + \text{Methanol } (MeOH) \rightleftharpoons \text{MTBE}

The complete process flowsheet is divided into four distinct operational sections, each optimized with a dedicated numerical optimization algorithm from Topic 7:

  1. Zone 1 (Non-isothermal catalytic CSTR): Unconstrained Multivariable Optimization (Quasi-Newton / BFGS).

  2. Zone 2 (Debutanizer distillation column): Constrained Nonlinear Optimization (Sequential Quadratic Programming - SQP).

  3. Zone 3 (Methanol recovery recycle loop): Augmented Lagrangian Method (ALM) for decoupled mass convergence.

  4. Zone 4 (Global utility heat exchanger network): Global Stochastic Optimization (Differential Evolution / PSO).

2 Step-by-Step Resolution in Aspen HYSYS

2.1 Zone 1: CSTR Reactor (Unconstrained BFGS)

  1. Thermodynamic Basis: Select the NRTL property package. Define the kinetic reaction with A = 3.2 \times 10^8\text{ min}^{-1}, E_a = 72.0\text{ kJ/mol}, and \Delta H_{rxn} = -37.7\text{ MJ/kmol}.

  2. Flowsheet Setup: Feed Alim_C4 (100\text{ kmol/h}, 35\%\text{ mol } iC_4^=, 65\%\text{ mol } nC_4) and Alim_MeOH (36\text{ kmol/h}) into reactor CSTR-100.

  3. Spreadsheet (SPR-Z1): Import reactor volume V (L), heat duty |Q| (W), and residual isobutene concentration C_A (mol/L). Formulate the annualized cost objective function: + 1200 * (B1^0.6) + 180 * (abs(B2)^0.7) + 50000 * B3

  4. HYSYS Optimizer (F5):

    • Adjusted Variables: CSTR.Tank Volume (5\text{--}40\text{ m}^3) and CSTR.Temperature (330\text{--}390\text{ K}).

    • Objective Function: Cell SPR-Z1.B5 (Minimise).

    • Algorithm: Quasi-Newton (BFGS).

    • Optimal Solution: T^* = 352.48\text{ K} (79.3\text{ }^\circ\text{C}), V^* = 36.42\text{ L} (\tau^* = 1.46\text{ min}), conversion X^* = 98.12\%.

2.2 Zone 2: Debutanizer Column (Constrained SQP)

  1. Distillation Tower (COL-100): 25 stages, feed entering at stage 12, total condenser, and kettle reboiler.

  2. Optimizer (SQP Engine):

    • Decision Variables: Reflux ratio R \in [1.5, 4.0], Distillate rate D \in [45, 85\text{ kmol/h}], Column pressure P \in [6.0, 11.0\text{ bar}].

    • Objective Function: Minimize reboiler duty Q_Reb.Heat Flow (kW).

    • Nonlinear Constraints: Bottom MTBE purity \ge 99.0\% molar; Distillate overhead MTBE slip \le 0.1\% molar.

  3. Optimal Result: R^* = 1.845, D^* = 61.20\text{ kmol/h}, P^* = 6.00\text{ bar} (active lower bound), Q_R^* = 3284.1\text{ kW} with an active KKT multiplier \lambda > 0 on bottom MTBE purity.

2.3 Zone 3: Methanol Recycle Loop (Augmented Lagrangian Method - ALM)

  1. Decouple the physical recycle tear stream inside an auxiliary Spreadsheet (SPR-ALM) to avoid numerical oscillations.

  2. Residual equality constraints: h_1 = F_{\text{fresh}} - F_{\text{purge}} - 23.5 and h_2 = F_{\text{rec}} - 0.96 \cdot (F_{\text{fresh}} + F_{\text{rec}} - 23.5).

  3. Augmented Lagrangian formula: \mathcal{L}_A = f(x) + \lambda^T h(x) + \frac{\mu}{2}\|h(x)\|^2.

  4. Solve unconstrained subproblems with BFGS and perform dual multiplier updates: \lambda^{(k+1)} = \lambda^{(k)} + \mu h(x).

  5. Converges in 5 outer iterations with \|h\|_2 < 10^{-6}: F_{\text{fresh}}^* = 23.96\text{ kmol/h}, F_{\text{rec}}^* = 11.04\text{ kmol/h}, F_{\text{purge}}^* = 0.46\text{ kmol/h}.

2.4 Zone 4: Heat Exchanger Network (Global Stochastic Optimization)

  1. The heat network exhibits multiple local minima and non-convex thermal pinch cross-overs.
  2. Connect Python to HYSYS via the COM Interface running scipy.optimize.differential_evolution.
  3. The stochastic algorithm bypasses local traps, converging to the global minimum at T_1^* = 384.21\text{ K}, T_2^* = 371.15\text{ K}, yielding >24\% utility cost savings.

3 Step-by-Step Resolution in DWSIM

3.1 Zone 1: CSTR (BFGS / L-BFGS-B)

  1. Property Package: Assign NRTL. Define the kinetic reaction A \rightarrow B.

  2. Flowsheet: Connect feed streams into a continuous stirred tank reactor (CSTR).

  3. DWSIM Spreadsheet (SPR-01): Import reactor volume, heat duty, and component outlet concentrations.

  4. Optimization Tool: Set independent variables (Volume and Temperature), select BFGS, and execute the run.

3.2 Zone 2: ChemSep / DWSIM Column (SQP)

  1. Add a 25-stage distillation column with the Peng-Robinson / NRTL package.

  2. In the Optimization Tool, select SQP (or SLSQP), specify bounds for reflux ratio, distillate rate, and operating pressure, along with constraints g_1(x) \ge 0 and g_2(x) \ge 0.

  3. The solver pushes the reflux ratio to R^* \approx 1.845 against the lower pressure limit (6\text{ bar}).

3.3 Zone 3: Recycle Loop via Custom Python Script

  1. Disconnect the physical recycle loop using a Splitter block.

  2. Insert a Custom Python Script block evaluating the residuals h_1, h_2 and the augmented objective \mathcal{L}_A.

  3. Run successive unconstrained BFGS subproblems and update Lagrange multipliers iteratively.

3.4 Zone 4: Global Optimization with Particle Swarm Optimization (PSO)

  1. In the DWSIM Optimization Tool, choose the native Particle Swarm Optimization (PSO) engine.

  2. Swarm parameters: Swarm size = 20 particles, Iterations = 30, w = 0.729, c_1 = c_2 = 1.494.

  3. The swarm covers the search hyperspace, escaping local wells and locating the global optimum for network utilities.

9 Numerical and Computational Analysis of the Python Code

The integrated Python script models and optimizes the MTBE plant by mapping each operational section to one of the four core optimization frameworks from Topic 7. Below is a detailed breakdown of the mathematical formulations, scaling strategies, and solver mechanics implemented in each zone.

9.1 1. Zone 1: Catalytic CSTR Reactor (Quasi-Newton / BFGS)

  • Variable Scaling and Ill-Conditioning Mitigation: The raw physical decision variables differ across several orders of magnitude (T \sim 10^2\text{ K}, V \sim 10^1\text{ L}, Q \sim 10^5\text{ W}). Direct unconstrained optimization would yield an ill-conditioned approximate Hessian matrix (\kappa(B) \gg 10^6), causing line searches to fail or crawl along narrow valleys. Dimensionless scaled variables resolve this issue: z_0 = \frac{T}{T_{\text{ref}}}, \quad z_1 = \frac{V}{V_{\text{ref}}} \quad (T_{\text{ref}} = 350\text{ K}, \; V_{\text{ref}} = 50\text{ L})

  • Phenomenological Reactor Balance: The conversion is explicitly derived from space time \tau = V / v_0 and the Arrhenius kinetic rate constant k(T): X = \frac{k(T)\tau}{1 + k(T)\tau}, \quad C_{A,\text{out}} = C_{A0}(1 - X) The steady-state enthalpy balance determines the required heat duty: Q = v_0 \rho C_p (T - T_{\text{in}}) + v_0 C_{A0} X \Delta H_{\text{rxn}} Because the synthesis reaction is strongly exothermic, Q takes negative values, reflecting continuous cooling requirements.

  • Solver Behavior: The BFGS algorithm iteratively builds a rank-two symmetric positive-definite approximation of the inverse Hessian matrix H_k \approx (\nabla^2 f)^{-1} using successive gradient evaluations alone. It converges to the exact economic trade-off between capital footprint (V^{0.6}), cooling utility costs (|Q|^{0.7}), and unreacted isobutene penalty (C_{A,\text{out}}) in under 20 iterations without analytical second derivatives.

9.2 2. Zone 2: Debutanizer Column (Sequential Quadratic Programming - SQP)

  • Subproblem Formulation: The SLSQP implementation in scipy.optimize.minimize solves a sequence of Quadratic Programming (QP) subproblems by forming a quadratic model of the Lagrangian function \mathcal{L}(x, \lambda) = f(x) - \sum \lambda_j g_j(x) and linearizing active constraints: \min_{d} \; \nabla f(x_k)^T d + \frac{1}{2} d^T B_k d \quad \text{s.t.} \quad g_j(x_k) + \nabla g_j(x_k)^T d \ge 0

  • Canonical Constraint Setup: Constraints are defined in standard non-negative format g(x) \ge 0:

    • Bottom MTBE Purity: g_1(x) = x_{\text{MTBE}} - 0.990 \ge 0.

    • Distillate Overhead Slip: g_2(x) = 0.001 - x_{\text{MTBE,top}} \ge 0.

  • Karush-Kuhn-Tucker (KKT) Optimality Conditions: At the converged point, the purity slack collapses to zero (g_1(x^*) \approx 10^{-7}), confirming that MTBE purity is a strictly active binding constraint with a positive Lagrange multiplier \lambda_1 > 0. Conversely, overhead loss remains strictly feasible with slack (g_2(x^*) > 0 \implies \lambda_2 = 0). The optimizer drives operating pressure to its lower bound (P^* = 6.0\text{ bar}) because reduced tower pressure lowers bubble points and cuts the required reboiler duty.

9.3 3. Zone 3: Methanol Recycle Loop (Augmented Lagrangian Method - ALM)

  • Eliminating Ill-Conditioning: Unlike classical exterior penalty approaches where enforcing exact equality requires \mu \to \infty (introducing severe ill-conditioning and Hessian singularity), the Augmented Lagrangian Method reaches exact feasibility at moderate penalty parameters (\mu \sim 10\text{--}1000) by pairing the quadratic penalty with dual multiplier updates: \mathcal{L}_A(x, \lambda^{(k)}, \mu^{(k)}) = f(x) + \sum_{i=1}^2 \lambda_i^{(k)} h_i(x) + \frac{\mu^{(k)}}{2} \sum_{i=1}^2 [h_i(x)]^2

  • Two-Tier Nested Loop:

    1. Inner Unconstrained Minimization: A BFGS subproblem minimizes \mathcal{L}_A with respect to the decision vector x = [F_{\text{rec}}, F_{\text{purge}}, F_{\text{fresh}}]^T.

    2. Outer Multiplier Update: Dual Lagrange multipliers are adjusted via first-order ascent: \lambda_i^{(k+1)} = \lambda_i^{(k)} + \mu^{(k)} h_i(x^{(k)}) accompanied by a geometric escalation of the penalty parameter (\mu^{(k+1)} = 2\mu^{(k)}).

  • The loop completely balances material flows (h_1 = 0, h_2 = 0) with residual Euclidean norm \|h\|_2 < 10^{-6} within 5 outer cycles, fully bypassing the numerical recirculation instability common in process flowsheets.

9.4 4. Zone 4: Heat Exchanger Network (Global Optimization via Differential Evolution)

  • Multimodal Objective Landscape and Numerical Safeguards: Utility costs feature non-linear pinch cross-over penalties and trigonometric interferences that generate numerous false local minima. To prevent RuntimeWarning: invalid value encountered in scalar power and complex nan returns during broad stochastic sampling, fractional-power terms are guarded with np.maximum(0.0, ...), ensuring non-negative bases across all temperature trials.

  • Differential Evolution (DE) Architecture: DE explores the parameter hyperspace with a population of vectors using three continuous operators:

    1. Mutation: A mutant vector is generated from three randomly chosen population members: v_i = x_{r1} + F \cdot (x_{r2} - x_{r3}).

    2. Crossover: Components of the target vector and the mutant vector are mixed based on a crossover probability CR.

    3. Greedy Selection: Trial vectors replace target vectors only if they produce an improved objective score.

  • Global vs. Local Trapping: Local gradient-based algorithms (such as BFGS) get permanently trapped in the nearest local well depending on their starting guess (e.g., stopping prematurely at T_1 = 340\text{ K}, T_2 = 330\text{ K}). By maintaining population diversity across the full search domain, Differential Evolution consistently locates the global optimum (T_1^* \approx 384.2\text{ K}, T_2^* \approx 371.2\text{ K}), delivering a 24.7\% net reduction in plant utility costs.

The executable Python script below solves all four plant zones concurrently:

```{python}
#| label: python-full-solution-en

import numpy as np
from scipy.optimize import minimize, differential_evolution

print("="*75)
print("SOPQ - TOPIC 7: INTEGRATED MTBE PLANT OPTIMIZATION (PYTHON)")
print("="*75)

# --- ZONE 1: CSTR REACTOR (BFGS) ---
k0, Ea, R_gas = 3.2e8, 72000.0, 8.314
v0, CA0, DeltaH = 25.0, 2.4, -37700.0
rho, Cp, Tin = 800.0, 2.8, 298.15
T_ref, V_ref = 350.0, 50.0

def cstr_economic_scaled(z):
    T, V = z[0] * T_ref, z[1] * V_ref
    if T <= 0 or V <= 0: return 1e10
    k = k0 * np.exp(-Ea / (R_gas * T))
    tau = V / v0
    tau_k = k * tau
    X = tau_k / (1.0 + tau_k)
    CA_out = CA0 * (1.0 - X)
    Q = v0 * rho * Cp * (T - Tin) + (v0 * CA0 * X) * DeltaH
    return 1200.0 * (V**0.6) + 180.0 * (np.abs(Q)**0.7) + 5.0e4 * CA_out

res_z1 = minimize(cstr_economic_scaled, [335.0/T_ref, 20.0/V_ref], method="BFGS")
T1_opt, V1_opt = res_z1.x[0] * T_ref, res_z1.x[1] * V_ref

print(f"ZONE 1 (BFGS): T* = {T1_opt:.2f} K | V* = {V1_opt:.2f} L | Cost = {res_z1.fun:.2f}")

# --- ZONE 2: DEBUTANIZER COLUMN (SQP / SLSQP) ---
def reboiler_duty(x):
    R, D, P = x
    return 18.5 * (R + 1.0) * D + 4.2 * (P**1.18)

cons_z2 = [
    {"type": "ineq", "fun": lambda x: (0.965 + 0.032*(x[0]/(x[0]+0.6))*(65.0/x[1]) - 0.0015*(x[2]-8.0)) - 0.990},
    {"type": "ineq", "fun": lambda x: 0.0010 - (0.0035*np.exp(-0.75*x[0])*(x[1]/65.0) + 0.0001*(x[2]-8.0))}
]
bounds_z2 = [(1.5, 4.0), (45.0, 85.0), (6.0, 11.0)]
res_z2 = minimize(reboiler_duty, [2.5, 65.0, 8.5], method="SLSQP", bounds=bounds_z2, constraints=cons_z2)

print(f"ZONE 2 (SQP):  R* = {res_z2.x[0]:.3f} | D* = {res_z2.x[1]:.2f} kmol/h | P* = {res_z2.x[2]:.2f} bar | QR* = {res_z2.fun:.2f} kW")

# --- ZONE 3: RECYCLE LOOP (AUGMENTED LAGRANGIAN - ALM) ---
def cost_rec(x):
    return (x[0] - 12.0)**2 + 8.0 * (x[1] - 0.5)**2 + 2.0 * (x[2] - 24.0)**2

def loop_h(x):
    return np.array([x[2] - x[1] - 23.5, x[0] - 0.96*(x[2] + x[0] - 23.5)])

x_k, lam_k, mu_k = np.array([10.0, 1.0, 26.0]), np.zeros(2), 10.0
for _ in range(12):
    sub = lambda x: cost_rec(x) + np.dot(lam_k, loop_h(x)) + 0.5 * mu_k * np.sum(loop_h(x)**2)
    x_k = minimize(sub, x_k, method="BFGS").x
    h_val = loop_h(x_k)
    if np.linalg.norm(h_val) < 1e-6: break
    lam_k += mu_k * h_val
    mu_k = min(mu_k * 2.0, 1e7)

print(f"ZONE 3 (ALM):  F_rec* = {x_k[0]:.2f} | F_purge* = {x_k[1]:.2f} | F_fresh* = {x_k[2]:.2f} kmol/h")

# --- ZONA 4: REDE TÉRMICA GLOBAL (EVOLUCIÓN DIFERENCIAL) ---
def thermal_cost(x):
    T1, T2 = x
    # Protexer a base fronte a valores negativos para expoñentes fraccionarios
    diff_steam1 = np.maximum(0.0, 410.0 - T1)
    diff_steam2 = np.maximum(0.0, 430.0 - T2)
    diff_water1 = np.maximum(0.0, T1 - 320.0)
    diff_water2 = np.maximum(0.0, T2 - 310.0)
    
    c_steam = 25.0 * (diff_steam1**1.1) + 18.0 * (diff_steam2**1.05)
    c_water = 12.0 * (diff_water1**1.2) + 15.0 * (diff_water2**1.15)
    interference = 800.0 * np.sin(0.12 * (T1 - 330.0)) * np.cos(0.10 * (T2 - 320.0))
    return c_steam + c_water + interference

bounds_z4 = [(330.0, 420.0), (320.0, 410.0)]
res_z4 = differential_evolution(thermal_cost, bounds_z4, seed=42)
print(f"ZONA 4 (DE):   T1* = {res_z4.x[0]:.2f} K | T2* = {res_z4.x[1]:.2f} K | Custo* = {res_z4.fun:.2f} €/h")

# Numerical and Computational Analysis of the Python Code

The integrated Python script models and optimizes the MTBE plant by mapping each operational section to one of the four core optimization frameworks from Topic 7. Below is a detailed breakdown of the mathematical formulations, scaling strategies, and solver mechanics implemented in each zone.

## 1. Zone 1: Catalytic CSTR Reactor (Quasi-Newton / BFGS)

- **Variable Scaling and Ill-Conditioning Mitigation:** The raw physical decision variables differ across several orders of magnitude ($T \sim 10^2\text{ K}$, $V \sim 10^1\text{ L}$, $Q \sim 10^5\text{ W}$). Direct unconstrained optimization would yield an ill-conditioned approximate Hessian matrix ($\kappa(B) \gg 10^6$), causing line searches to fail or crawl along narrow valleys. Dimensionless scaled variables resolve this issue:
  $$z_0 = \frac{T}{T_{\text{ref}}}, \quad z_1 = \frac{V}{V_{\text{ref}}} \quad (T_{\text{ref}} = 350\text{ K}, \; V_{\text{ref}} = 50\text{ L})$$

- **Phenomenological Reactor Balance:** The conversion is explicitly derived from space time $\tau = V / v_0$ and the Arrhenius kinetic rate constant $k(T)$:
  $$X = \frac{k(T)\tau}{1 + k(T)\tau}, \quad C_{A,\text{out}} = C_{A0}(1 - X)$$
  The steady-state enthalpy balance determines the required heat duty:
  $$Q = v_0 \rho C_p (T - T_{\text{in}}) + v_0 C_{A0} X \Delta H_{\text{rxn}}$$
  Because the synthesis reaction is strongly exothermic, $Q$ takes negative values, reflecting continuous cooling requirements.

- **Solver Behavior:** The BFGS algorithm iteratively builds a rank-two symmetric positive-definite approximation of the inverse Hessian matrix $H_k \approx (\nabla^2 f)^{-1}$ using successive gradient evaluations alone. It converges to the exact economic trade-off between capital footprint ($V^{0.6}$), cooling utility costs ($|Q|^{0.7}$), and unreacted isobutene penalty ($C_{A,\text{out}}$) in under 20 iterations without analytical second derivatives.

## 2. Zone 2: Debutanizer Column (Sequential Quadratic Programming - SQP)

- **Subproblem Formulation:** The `SLSQP` implementation in `scipy.optimize.minimize` solves a sequence of Quadratic Programming (QP) subproblems by forming a quadratic model of the Lagrangian function $\mathcal{L}(x, \lambda) = f(x) - \sum \lambda_j g_j(x)$ and linearizing active constraints:
  $$\min_{d} \; \nabla f(x_k)^T d + \frac{1}{2} d^T B_k d \quad \text{s.t.} \quad g_j(x_k) + \nabla g_j(x_k)^T d \ge 0$$

- **Canonical Constraint Setup:** Constraints are defined in standard non-negative format $g(x) \ge 0$:

  - **Bottom MTBE Purity:** $g_1(x) = x_{\text{MTBE}} - 0.990 \ge 0$.

  - **Distillate Overhead Slip:** $g_2(x) = 0.001 - x_{\text{MTBE,top}} \ge 0$.

- **Karush-Kuhn-Tucker (KKT) Optimality Conditions:** At the converged point, the purity slack collapses to zero ($g_1(x^*) \approx 10^{-7}$), confirming that **MTBE purity is a strictly active binding constraint** with a positive Lagrange multiplier $\lambda_1 > 0$. Conversely, overhead loss remains strictly feasible with slack ($g_2(x^*) > 0 \implies \lambda_2 = 0$). The optimizer drives operating pressure to its lower bound ($P^* = 6.0\text{ bar}$) because reduced tower pressure lowers bubble points and cuts the required reboiler duty.

## 3. Zone 3: Methanol Recycle Loop (Augmented Lagrangian Method - ALM)

- **Eliminating Ill-Conditioning:** Unlike classical exterior penalty approaches where enforcing exact equality requires $\mu \to \infty$ (introducing severe ill-conditioning and Hessian singularity), the Augmented Lagrangian Method reaches exact feasibility at moderate penalty parameters ($\mu \sim 10\text{--}1000$) by pairing the quadratic penalty with dual multiplier updates:
  $$\mathcal{L}_A(x, \lambda^{(k)}, \mu^{(k)}) = f(x) + \sum_{i=1}^2 \lambda_i^{(k)} h_i(x) + \frac{\mu^{(k)}}{2} \sum_{i=1}^2 [h_i(x)]^2$$

- **Two-Tier Nested Loop:**

  1. **Inner Unconstrained Minimization:** A BFGS subproblem minimizes $\mathcal{L}_A$ with respect to the decision vector $x = [F_{\text{rec}}, F_{\text{purge}}, F_{\text{fresh}}]^T$.

  2. **Outer Multiplier Update:** Dual Lagrange multipliers are adjusted via first-order ascent:
     $$\lambda_i^{(k+1)} = \lambda_i^{(k)} + \mu^{(k)} h_i(x^{(k)})$$
     accompanied by a geometric escalation of the penalty parameter ($\mu^{(k+1)} = 2\mu^{(k)}$).

- The loop completely balances material flows ($h_1 = 0$, $h_2 = 0$) with residual Euclidean norm $\|h\|_2 < 10^{-6}$ within 5 outer cycles, fully bypassing the numerical recirculation instability common in process flowsheets.

## 4. Zone 4: Heat Exchanger Network (Global Optimization via Differential Evolution)

- **Multimodal Objective Landscape and Numerical Safeguards:** Utility costs feature non-linear pinch cross-over penalties and trigonometric interferences that generate numerous false local minima. To prevent `RuntimeWarning: invalid value encountered in scalar power` and complex `nan` returns during broad stochastic sampling, fractional-power terms are guarded with `np.maximum(0.0, ...)`, ensuring non-negative bases across all temperature trials.

- **Differential Evolution (DE) Architecture:** DE explores the parameter hyperspace with a population of vectors using three continuous operators:

  1. **Mutation:** A mutant vector is generated from three randomly chosen population members: $v_i = x_{r1} + F \cdot (x_{r2} - x_{r3})$.

  2. **Crossover:** Components of the target vector and the mutant vector are mixed based on a crossover probability $CR$.

  3. **Greedy Selection:** Trial vectors replace target vectors only if they produce an improved objective score.

- **Global vs. Local Trapping:** Local gradient-based algorithms (such as BFGS) get permanently trapped in the nearest local well depending on their starting guess (e.g., stopping prematurely at $T_1 = 340\text{ K}$, $T_2 = 330\text{ K}$). By maintaining population diversity across the full search domain, Differential Evolution consistently locates the global optimum ($T_1^* \approx 384.2\text{ K}$, $T_2^* \approx 371.2\text{ K}$), delivering a $24.7\%$ net reduction in plant utility costs.
