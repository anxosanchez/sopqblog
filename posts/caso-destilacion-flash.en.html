2 1. Introduction and Process Context

Flash distillation is an essential unit operation across natural gas processing, oil refineries, and petrochemical complexes. It removes light fractions from crude feeds or stabilizes hydrocarbon streams before complex distillation column trains.

In this benchmark case, an isothermal flash vessel operating at steady-state is fed with a ternary paraffin mixture: * n-Pentane (n\text{-C}_5\text{H}_{12}): z_1 = 0.50 (light key component) * n-Hexane (n\text{-C}_6\text{H}_{14}): z_2 = 0.30 (intermediate component) * n-Heptane (n\text{-C}_7\text{H}_{16}): z_3 = 0.20 (heavy key component)

Feed enters at F = 100.0\text{ kmol/h}, with inlet conditions T_F = 30.0^\circ\text{C} and P_F = 3.00\text{ bar}. Downstream of the control expansion valve and preheater, the drum operates at T = 78.4^\circ\text{C} and P = 1.20\text{ bar}.

3 2. Thermodynamic Foundation and Governing Equations

3.1 2.1 Vapor-Liquid Equilibrium (VLE) Criterion

Phase equilibrium requires equality of chemical potentials, which corresponds to equality of component fugacities:

f_i^V(T, P, \mathbf{y}) = f_i^L(T, P, \mathbf{x}) \quad \forall i \in \{1, \dots, C\}

Defining fugacity coefficients \phi_i^V and \phi_i^L:

y_i \phi_i^V P = x_i \phi_i^L P \implies K_i \equiv \frac{y_i}{x_i} = \frac{\phi_i^L(T, P, \mathbf{x})}{\phi_i^V(T, P, \mathbf{y})}

For hydrocarbons at moderate pressures (P \approx 1.2\text{ bar}), equilibrium distribution coefficients K_i evaluated with the Peng-Robinson Equation of State yield: * K_1 (n\text{-Pentane}) = 2.4410 * K_2 (n\text{-Hexane}) = 0.9450 * K_3 (n\text{-Heptano}) = 0.3815

3.2 2.2 Derivation of the Rachford-Rice Equation

From total and component material balances:

F = V + L \implies 1 = \psi + \frac{L}{F} \quad \text{where } \psi \equiv \frac{V}{F}

F z_i = V y_i + L x_i = V (K_i x_i) + L x_i \implies x_i = \frac{z_i}{1 + \psi (K_i - 1)}

Since \sum_{i=1}^{C} y_i - \sum_{i=1}^{C} x_i = 0, substituting y_i = K_i x_i:

\mathcal{F}(\psi) = \sum_{i=1}^{C} (y_i - x_i) = \sum_{i=1}^{C} \frac{z_i (K_i - 1)}{1 + \psi (K_i - 1)} = 0

The objective function \mathcal{F}(\psi) is monotonically decreasing in the physical range [0, 1], guaranteeing rapid quadratic convergence via Newton-Raphson:

\mathcal{F}'(\psi) = -\sum_{i=1}^{C} \frac{z_i (K_i - 1)^2}{[1 + \psi (K_i - 1)]^2} < 0

6 5. Python Numerical Solver

import numpy as np

# Feed specs and operating conditions
components = ["n-Pentane", "n-Hexane", "n-Heptane"]
z = np.array([0.50, 0.30, 0.20])
K = np.array([2.4410, 0.9450, 0.3815])
F_total = 100.0  # kmol/h

def rachford_rice(psi: float, z: np.ndarray, K: np.ndarray) -> float:
    """Rachford-Rice objective function."""
    return np.sum(z * (K - 1.0) / (1.0 + psi * (K - 1.0)))

def rachford_rice_deriv(psi: float, z: np.ndarray, K: np.ndarray) -> float:
    """Analytical first derivative dF/d(psi)."""
    return -np.sum(z * (K - 1.0)**2 / (1.0 + psi * (K - 1.0))**2)

# Solution via Newton-Raphson
psi = 0.5  # Initial seed
tolerance = 1e-9
max_iter = 50

for iteration in range(max_iter):
    f_val = rachford_rice(psi, z, K)
    f_prime = rachford_rice_deriv(psi, z, K)
    step = f_val / f_prime
    psi = psi - step
    if abs(step) < tolerance:
        print(f"✓ Convergence reached in {iteration + 1} iterations: psi = {psi:.6f}")
        break

# Compute equilibrium phase compositions
x = z / (1.0 + psi * (K - 1.0))
y = K * x

V_flow = F_total * psi
L_flow = F_total * (1.0 - psi)

print(f"Vapor Flow (V):   {V_flow:.3f} kmol/h")
print(f"Liquid Flow (L):  {L_flow:.3f} kmol/h")
print(f"Vapor Composition (y):   {dict(zip(components, np.round(y, 4)))}")
print(f"Liquid Composition (x):  {dict(zip(components, np.round(x, 4)))}")
print(f"Consistency: sum(x) = {np.sum(x):.6f}, sum(y) = {np.sum(y):.6f}")

## 5. Python Numerical Solver

```python
import numpy as np

# Feed specs and operating conditions
components = ["n-Pentane", "n-Hexane", "n-Heptane"]

K = np.array([2.4410, 0.9450, 0.3815])
```
